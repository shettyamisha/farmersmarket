# 🥦 Farmers Market Website

A full-stack web application that connects local farmers directly with consumers to facilitate the online sale of fresh produce.

---

## 🚀 Features

- 👥 User Registration and Login (Farmers & Consumers)
- 🛍️ Product Listings with Dynamic Display
- 🛒 Shopping Cart and Checkout
- 💳 Payment Integration (Stripe & PayPal)
- 🔔 Order Tracking with Real-Time Notifications
- 📱 Responsive Frontend using React
- 🗄️ MySQL for Persistent Data Storage 

---

## 🛠️ Tech Stack

| Layer        | Technology         |
|--------------|--------------------|
| Frontend     | React, HTML, CSS   |
| Backend      | Python, Flask      |
| Database     | MySQL              |
| Payment      | PayPal, Stripe     |
| Auth         | JWT (JSON Web Tokens) |

---

## 🧑‍💻 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/farmersmarket.git
   cd farmersmarket
---

2. **Backend Setup**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate  # or venv\Scripts\activate on Windows
   pip install -r requirements.txt
   python run.py
---
   
4. **Frontend Setup**
   ```bash
   cd farmers-frontend
   npm install
   npm start
---
